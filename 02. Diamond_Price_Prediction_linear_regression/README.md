# 중량과 품질 등급(4C)으로 다이아몬드 가격을 설명할 수 있는가

## 요약 (Executive Summary)

- **데이터:** Diamonds (Kaggle) / https://www.kaggle.com/datasets/shivam2503/diamonds
- **규모:** 53,940 관측치 × 10 변수 (중복 146건 제거 후 53,794건)
- **문제 유형:** 예측(회귀)

> 다이아몬드 53,794개의 가격(`price`)을 중량(`carat`)·컷(`cut`)·색상(`color`)·투명도(`clarity`) 등 9개 변수로 설명했다.
> 기계적 전처리(로그 변환 · 이상치 대체 · VIF · 후진소거)와 도메인 지식 기반 변수 제거를 각각 체크포인트로 나누어 9개 모형을 비교했고,
> **도메인 지식으로 중복 변수(`x`·`y`·`z`)를 걷어낸 뒤 로그 변환과 이상치 대체를 적용한 모형(독립변수 18개)** 을 최종 채택했다.
> 조정 R² = 0.983(원본 척도 R² = 0.960), RMSE = 796.88달러로, 기준선 모형(독립변수 20개, RMSE 1,131.51) 대비 **변수는 2개 줄이고 RMSE를 낮췄다**(기준선의 Gap 41.990%).
> 기계적 선택의 최고 모형(`2_이상치대체`, 독립변수 21개, RMSE 831.95)보다도 **변수는 3개 적고 RMSE는 낮았다**(해당 모형의 Gap 4.400%).
> 가격을 가장 크게 좌우하는 요인은 **중량(`carat`, β = 1.086)** 이었으며, 이는 2위인 `clarity_5`(β = 0.306)의 약 3.5배였다.
> 즉 4C 가운데 가격을 가장 강하게 설명하는 것은 **중량**이며, 중량이 1% 늘면 가격은 약 1.88% 오른다.

## 회고

- **새로 익힌 기법:** 서열형 변수(`cut`·`color`·`clarity`)를 **더미 변수로 바꾸고 기준 범주를 확인**해 계수를 "기준 대비 % 차이"로 읽는 방법, 종속변수와 `carat`에 모두 로그를 씌운 **로그-로그 모형의 계수를 탄력성으로 해석**하는 방법(`carat` 1% ↑ → 가격 약 1.88% ↑), 그리고 전처리를 하나씩 누적한 **체크포인트로 기계적 선택과 도메인 지식 기반 선택을 한 표에서 비교**하는 방식이다.
- **막혔던 지점과 해결 방법:**
  - ① VIF 기반 공선성 제거가 상관이 동률인 `carat`·`x`·`y`·`z` 가운데 `z`를 남겨 RMSE가 1,096.54로 오히려 나빠졌다 → **도메인 지식으로 `carat`을 남기고 `x`·`y`·`z`를 직접 제거한 버전을 따로 만들어 성능표에서 비교**하는 방식으로 풀었다.
  - ② 도메인 지식으로 `x`·`y`·`z`만 제거한 모형(`5_도메인_기준선`)은 RMSE 1,155.81로 9개 중 꼴찌였다 → **로그 변환을 더하자 798.87로 개선**되어, 변수 선택과 변환은 함께 가야 함을 확인했다.
  - ③ 단변량 ANOVA에서는 등급 순서와 집단 평균 순서가 맞지 않았는데, `carat`을 통제한 최종 모형에서는 계수의 크기 순서가 실제 등급 순서와 일치했다 → 다변량 통제의 결과로 확인하고 그 자체를 인사이트로 정리했다.
- **다음 데이터셋에서 보완할 점:** 가정 위반을 **발견하는 것**까지는 했지만 **해소하는 것**은 등분산 하나(HC3)뿐이었다. 선형성 위배에 대해 `log(carat)`의 제곱항·구간화·등급과의 상호작용항 같은 대안을 준비해 두고, 학습/검증 분할 없이 전체 데이터로 적합한 탓에 RMSE가 학습 데이터 기준 값이므로 처음부터 **학습/검증 분할(교차검증)을 설계**해 성능 수치를 일반화 가능한 값으로 보고하고 싶다.
